# UI 边界与背景优化记录

验证日期：2026-06-11

## 本轮目标

针对用户截图反馈的 4 个问题进行修正：

- 头像视觉间隙偏大。
- 左下角和右下角头像看起来超出实际边界。
- 网页 UI 与游戏画布没有对齐。
- 主游戏界面缺少正式背景。

## 修正内容

- 头像切图透明边距从 `18` 收紧到 `4`。
- 头像绘制尺寸从 `2.28r` 改为 `2r`，让视觉大小与物理半径一致。
- 物理左右墙改为与可见桶线同一位置。
- 桶底上移到 `1165`，给底部按钮留出真实空间。
- 网页端新增 `game-shell` 容器，顶部 HUD、目标卡、记录卡和底部按钮都跟随游戏画布宽度。
- 生成并接入主玩法背景 `game_bg.jpg`。
- 清理公开展示名和资源名中的旧梗命名，改为原创可爱命名。
