# 静音开关商业化补齐记录

验证日期：2026-06-11

## 本轮目标

补齐商业化试玩包中的基础声音控制能力，让玩家可以一键关闭声音，并在下次进入时保留选择。

## 新增内容

- 网页试玩端底部新增 `声/静` 圆形按钮。
- 微信小游戏端底部新增 `声/静` 圆形按钮。
- 静音偏好在本地持久化保存。
- 静音后不会继续播放按钮、掉落、合成、失败等音效。

## 验证覆盖

```text
npm run build
npm run validate
npm run test:wechat
npm run test:viewport
```

验证结论：

```text
build: ok
validate: ok
test:wechat: ok
test:viewport: ok
```

补充断言：

- `validate` 检查网页端和微信端均包含静音偏好。
- `test:wechat` 检查静音偏好写入本地存储。
- `test:wechat` 检查静音后不会额外播放音效。
- `test:viewport` 检查移动端页面存在声音开关。
