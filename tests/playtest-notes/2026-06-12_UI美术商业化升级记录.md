# UI 美术商业化升级记录

验证日期：2026-06-12

## 本轮目标

把当前 UI 从“能玩原型”继续推进到更像可交付微信休闲小游戏的视觉标准，重点处理启动页、HUD、进度条、按钮、桶线和包体。

## 已完成

- 使用内置 imagegen 生成新版启动页背景。
- 保存母图：`art/generated/ui_splash_background_20260612.png`。
- 保存压缩运行图：`art/final/ui_splash_750x1334.jpg`。
- 网页端接入：`game/web-prototype/public/assets/ui/splash_bg.jpg`。
- 微信端接入：`game/wechat-minigame/assets/ui/splash_bg.jpg`。
- 启动页标题和按钮改为代码层展示，避免图片中文字不稳定。
- 主界面 HUD 改成更轻、更亮的商业休闲小游戏面板。
- 等级进度条改成带头像的小徽章，提升合成链识别度。
- 画布桶线、警戒线和落点虚线做了质感强化。
- 移除运行时旧概念图，降低微信主包体积。

## 风险控制

- 新启动图不包含文字，不包含现成表情包、版权角色或平台水印。
- 亿仔正式形象仍使用第 11 级确定资产，不依赖启动页生成图。
- 微信端触控区域已同步新版开始按钮位置。
