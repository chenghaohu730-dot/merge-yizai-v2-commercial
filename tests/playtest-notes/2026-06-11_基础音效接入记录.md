# 基础音效接入记录

验证日期：2026-06-11

## 本轮目标

补齐商业化试玩验证包的基础声音反馈，让掉落、合成、按钮、亿仔庆祝和失败都有即时反馈。

## 新增资源

音效文件已同步到：

```text
game/web-prototype/public/assets/audio
game/wechat-minigame/assets/audio
```

文件：

```text
drop.wav
merge.wav
big_merge.wav
yizai.wav
game_over.wav
button.wav
```

这些音效由本地脚本生成，避免外部版权风险，包体可控。

## 接入范围

- 网页端：使用 `HTMLAudioElement`，首次开始游戏后解锁播放。
- 微信小游戏端：使用 `wx.createInnerAudioContext`，接口不可用时静默降级。
- 触发点：开始/按钮、掉落、普通合成、高级合成、亿仔爆分、失败结算。

## 验证覆盖

- `npm run validate`：检查网页端和微信端音效文件存在，并检查微信端音频接口引用。
- `npm run test:wechat`：模拟微信音频接口，确认创建音频上下文并发生按钮音效和掉落音效播放。
- `npm run build`：确认网页端音频引用不影响构建。

## 本轮验证结果

- `npm run build` 通过。
- `npm run validate` 通过，检查项提升到 `27` 项。
- 微信小游戏主包约 `3.09MB`，仍低于 4MB。
- `npm run test:wechat` 通过，模拟环境创建 `6` 个音频上下文，触发 `2` 次播放。
- `npm run test:viewport` 通过，移动端布局未受音效接入影响。
- `node --check game/wechat-minigame/game.js` 通过。
- 本地预览服务下 6 个音效 URL 均返回 `200`。
- 内置浏览器错误日志为 `0`。

## 后续建议

当前音效为基础版，正式上线前建议替换为更有品牌记忆点的专业音效，并做真机音量、延迟和静音模式测试。
