# 自动长测稳定性记录

验证日期：2026-06-11

## 本轮目标

在真机长测之前，增加一条自动稳定性门槛：模拟连续试玩操作，提前发现画面空白、前端报错、状态卡死、基础交互失效等问题。

## 新增命令

在 `game/web-prototype` 目录执行：

```text
npm run test:soak
```

脚本会自动启动本地试玩页，不依赖手动打开浏览器。

## 覆盖内容

- iPhone 12 移动视口启动试玩。
- 切换静音。
- 暂停并恢复。
- 连续模拟 32 次掉落。
- 触发 14 次测试合成。
- 检查没有页面错误和控制台错误。
- 检查分数增长、最高等级增长、游戏状态未卡死。
- 检查画布不是空白。
- 输出最终截图和 `summary.json`。
