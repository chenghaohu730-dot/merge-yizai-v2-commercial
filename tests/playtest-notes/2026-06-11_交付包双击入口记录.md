# 交付包双击入口记录

验证日期：2026-06-11

## 本轮目标

降低交付包接手门槛，让非开发人员解压后可以直接双击完成常见操作。

## 新增入口

交付包根目录会自动生成：

```text
双击_打开微信小游戏工程.bat
双击_查看导入说明.bat
双击_自检交付包.bat
自检交付包.ps1
```

## 入口用途

| 文件 | 用途 |
| --- | --- |
| `双击_打开微信小游戏工程.bat` | 打开 `01_微信小游戏工程`，方便直接在微信开发者工具里选择 |
| `双击_查看导入说明.bat` | 打开傻瓜式导入说明 |
| `双击_自检交付包.bat` | 调用 `自检交付包.ps1` 做本地交付包完整性检查 |
| `自检交付包.ps1` | 检查关键文件、主包大小、AppID 口径、分享图引用、校验和和敏感文件 |

## 验证要求

每次生成交付包后应执行：

```text
npm run audit:release -- "交付包目录"
powershell -NoProfile -ExecutionPolicy Bypass -File "交付包目录\自检交付包.ps1"
```
