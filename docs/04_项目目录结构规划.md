# 项目目录结构规划

## 当前建议结构

```text
微信小游戏/
├─ AGENTS.md
├─ README.md
├─ docs/
│  ├─ 01_完整玩法规则表.md
│  ├─ 02_11级抽象头像美术清单.md
│  ├─ 03_Cocos开发任务清单.md
│  └─ 04_项目目录结构规划.md
├─ art/
│  ├─ prompts/
│  ├─ source/
│  ├─ generated/
│  └─ final/
├─ game/
│  └─ cocos-project/
├─ exports/
│  ├─ wechat-dev/
│  └─ builds/
└─ tests/
   ├─ playtest-notes/
   └─ device-checks/
```

## 文件夹说明

| 文件夹 | 用途 |
| --- | --- |
| `docs` | 策划、规则、任务拆分 |
| `art/prompts` | 头像和 UI 的生成提示词 |
| `art/source` | 用户提供或人工制作的源文件 |
| `art/generated` | AI 生成过程图 |
| `art/final` | 游戏正式使用 PNG |
| `game/cocos-project` | Cocos Creator 工程 |
| `exports/wechat-dev` | 微信小游戏开发导出 |
| `exports/builds` | 阶段版本包 |
| `tests/playtest-notes` | 试玩记录和问题 |
| `tests/device-checks` | 真机适配记录 |

## 执行顺序

1. 完成 docs 定稿。
2. 检查 Cocos Creator 和微信开发者工具。
3. 如本机环境可用，创建 `game/cocos-project`。
4. 先做灰盒原型。
5. 生成或制作头像资源。
6. 接入正式资源。
7. 导出微信小游戏体验版。
