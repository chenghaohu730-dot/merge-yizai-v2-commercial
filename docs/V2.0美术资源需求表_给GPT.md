# 《合成亿仔 V2.0》美术资源需求表

用途：把这份表交给 Grok / 图片生成与确定性导出工具，用来从零生产《合成亿仔 V2.0》美术资源。

最高优先级边界：已发布 V1 只作行为和代码参考，V1 与当前旧 Cocos 的全部美术、截图和既有风格均不得复用或作为生成参考。详细规则见 `docs/13_《合成亿仔》V2.0美术全量重制硬性边界.md`。

## 全局生成规则

| 规则项 | 要求 |
|---|---|
| 设计基准 | 竖屏 750x1334，适配微信小游戏手机屏幕 |
| 美术风格 | 尚未锁定；先制作 4–6 个原创商业风格方向。可以对标《开心消消乐》等头部休闲游戏的完成度、层级、色彩、触感和反馈节奏，但不得复制可识别角色、Logo、图标、布局、按钮或商业外观 |
| 旧资源禁用 | 旧背景、UI、按钮、面板、头像、皮肤、图标、粒子、宣传图和旧风格不得复制、缩放、改色、裁切、拼接、图生图或重新导入 V2 |
| 资源拆分 | 必须分层导出，不要把动态文字、数字、任务进度、排行榜名次烘焙进背景图 |
| 按钮状态 | 默认按钮需要真实 normal / pressed / disabled：pressed 视觉下移 6px、顶部高光减弱、底部厚度缩短且热区不动；disabled 降低饱和和明度但保留轮廓，不能只变暗或改透明度 |
| 透明背景 | UI、按钮、弹窗、球体、图标优先 PNG 透明背景 |
| 玩法可读性 | 主游戏玩法仓背景必须低干扰，球体必须比背景更醒目 |
| 文字处理 | 除经批准的品牌 Logo 和确定性校正的 `MAEE` 外，所有按钮文案、数字和状态文字都由 Cocos 实时渲染；生成图只交付无文字底板 |
| 亿仔 IP | 所有涉及亿仔的生成和编辑，必须使用本机 `art/source/yizai_highest_source.png` 作为唯一正式身份参考，并记录其 SHA256 |
| 亿仔使用限制 | 工具不能真实读取参考图时停止亿仔任务；不得仅靠文字猜测。可以适配选定的新风格，但不得改变白熊主体、橙黄色口鼻区、黑色大鼻子、粗眉毛、头部装饰物和头饰正面 `MAEE` |
| MAEE 限制 | MAEE 不可省略、不可替换、不可拼错、不可镜像、不可倒置、不可被遮挡 |
| 命名规则 | 按表格中的资源名导出，英文小写加下划线，方便程序接入 |
| 文件后缀 | 表格资源名默认不写后缀；最终交付文件必须带 `.png`、`.jpg` 或约定后缀 |

## 接入补充规则

### 按钮文字与动态文字

| 类型 | 是否可以写进图片 | 示例 | 说明 |
|---|---|---|---|
| 固定按钮文字 | 不可以 | 开始游戏、任务、商店、排行榜、领取、购买、使用、再来一局、分享成绩、返回大厅 | 统一由 Cocos Label 渲染，避免 AI 乱码并支持状态、语言与无障碍调整 |
| 动态数据 | 不可以 | 分数、最高分、今日目标进度、亿仔币数量、任务进度、排行榜昵称、排行榜分数 | 必须由代码实时渲染 |
| 可变状态文案 | 建议不写死 | 今日目标已完成、已领取、已拥有、使用中、金币不足 | 如果状态会变化，优先代码渲染；如必须做图，需要单独列出所有状态图 |

### 球体物理安全区规则

所有 `face_01` 到 `face_11`，以及所有商店皮肤球，必须遵守：

| 项目 | 规则 |
|---|---|
| 画布尺寸 | 512x512 |
| 主体圆心 | 256,256 |
| 主体最大直径 | 460px |
| 透明安全边距 | 四周至少 26px |
| 外轮廓 | 必须接近正圆，方便圆形碰撞 |
| 装饰物 | 不得超出圆形碰撞轮廓；不能形成尖角或大面积外伸 |
| 阴影 | 可在圆形安全区内做轻微阴影，不要超出透明安全边距 |
| 碰撞圆 | 程序默认按圆心 256,256、直径 460px 建立碰撞参考 |

`face_11_yizai` 额外要求：

- 帽子、头饰、MAEE、粗眉毛、黑色大鼻子、橙黄色口鼻区都必须在 460px 主体安全圆内。
- MAEE 必须正向、清晰、无遮挡。
- 亿仔可以有头饰高度感，但不能让整体碰撞读起来像椭圆或不规则形。

### Cocos 坐标转换规则

本表所有布局坐标均为设计坐标，原点在左上角，设计尺寸为 750x1334。

如果 Cocos Creator 的 Canvas 使用中心点为原点，则按以下公式转换：

```text
cocosX = x + w / 2 - 375
cocosY = 667 - (y + h / 2)
```

点位坐标转换，例如 `dropper_anchor`：

```text
cocosX = x - 375
cocosY = 667 - y
```

### 安全区与屏幕适配规则

750x1334 是设计基准，程序需要按等比缩放适配不同手机屏幕。

- 顶部 HUD 必须避开刘海屏、状态栏和微信胶囊按钮。
- 底部 `control_bar` 必须避开系统手势条和底部安全区。
- 关键操作按钮不得贴边，建议与屏幕物理边缘至少保留 24px 设计安全距离。
- 长屏可以扩展背景和外壳上下空间，但玩法仓、物理区域、按钮大小不得被非等比拉伸。
- 短屏优先保证玩法仓、开始按钮、底部控制按钮可见；装饰元素可以裁切或缩小。
