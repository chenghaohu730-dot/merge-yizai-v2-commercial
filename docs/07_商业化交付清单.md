## 仍需上线前处理

| 模块 | 说明 |
| --- | --- |
| 正式 AppID | 当前仍为 `touristappid`，上传体验版前必须替换 |
| 微信开发者工具预览 | 本机已找到微信开发者工具和 CLI；预览码仍需要登录态、真实 AppID 和人工导入验证 |
| 真机长测 | 需要至少 10-20 局手机试玩，继续调重力、摩擦、警戒线 |
| 音效精修 | 当前已有基础音效，正式商业版建议后续替换为更有品牌记忆点的专业音效 |
| 合规资料 | 已准备基础口径，正式提审前需要按微信后台实际字段填写 |
| 排行榜/广告 | 当前只做预留，不接服务器、不接激励视频 |

## 交付验收命令

在 `game/web-prototype` 目录执行：

```text
npm run build
npm run validate
npm run test:wechat
npm run test:viewport
npm run test:soak
```

验收通过后，检查以下截图：

```text
tests/device-checks/viewport-smoke/iphone-12-start.png
tests/device-checks/viewport-smoke/iphone-12-playing.png
tests/device-checks/viewport-smoke/compact-android-start.png
tests/device-checks/viewport-smoke/compact-android-playing.png
tests/device-checks/gameplay-soak/iphone-12-soak-final.png
tests/device-checks/avatar-art/cute-avatar-chain-20260611.png
tests/device-checks/avatar-art/perfect-round-faces-20260612.png
```

生成商业化交付包：

```text
npm run release
npm run audit:release
```

交付包内也包含双击入口：

```text
双击_打开微信小游戏工程.bat
双击_查看导入说明.bat
双击_自检交付包.bat
```

傻瓜式导入说明：

```text
docs/09_交付包导入说明_傻瓜版.md
docs/10_商业化验收报告.md
```
