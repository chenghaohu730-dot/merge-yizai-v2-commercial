# 《合成亿仔》商业化验收报告

验收日期：2026-06-27

## 验收结论

当前版本达到“商业化试玩交付包”标准：可以用于内部评审、合作方试玩、微信开发者工具导入、视觉和手感验收。

## 上线前人工事项

| 事项 | 责任边界 | 说明 |
| --- | --- | --- |
| 正式 AppID | 需要账号资料 | 当前工程保留 `touristappid`，避免交付包误带真实 AppID |
| 开发者工具预览 | 需要登录态和真实 AppID | 本机工具和 CLI 已找到，导入后仍需账号权限生成预览码 |
| 真机长测 | 需要手机扫码 | 至少 10-20 局，重点看碰撞手感、警戒线、分享图裁切和音量 |
| 微信后台提审 | 需要小游戏后台权限 | 使用 `docs/08_上线资料包.md` 的名称、简介、隐私说明和素材 |
| 专业音效精修 | 可选增强项 | 当前音效可用，后续可替换为更有品牌记忆点的专业音效 |
