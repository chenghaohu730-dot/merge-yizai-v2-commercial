## 隐私与数据说明

当前版本不接服务器、不接账号、不上传玩家个人数据。

本地保存内容：

| 数据 | 用途 |
| --- | --- |
| 最高分 | 记录玩家本机最高成绩 |
| 累计挑战局数 | 展示本地挑战次数 |
| 今日目标进度 | 展示每日目标完成状态 |
| 亿仔合成次数 | 展示本地成就感 |
| 静音偏好 | 记住玩家是否关闭声音 |

建议提审隐私口径：

```text
本小游戏仅在用户设备本地保存游戏进度、分数记录和声音开关偏好，用于展示最高分、今日目标、本地挑战次数和记住静音设置；当前版本不收集、上传或共享个人身份信息。
```

## 提审前人工验收清单

1. 用微信开发者工具导入 `game/wechat-minigame`。
2. 替换正式小游戏 AppID。
3. 运行模拟器，确认启动页、开始、掉落、合成、暂停、结算正常。
4. 点击右上角分享，确认分享图为正式分享卡。
5. 真机扫码试玩至少 10 局。
6. 检查亿仔头像中 `MAEE` 在游戏中可辨认。
7. 检查底部图片按钮可点击，声音开关、暂停和重开都正常。
8. 确认提审后台填写的名称、简介、图标、隐私说明与本资料包一致。
