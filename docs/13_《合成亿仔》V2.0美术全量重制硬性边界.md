# 《合成亿仔》V2.0 美术全量重制硬性边界

文档版本：1.0

状态：用户已确认，属于 V2.0 美术生产最高优先级口径。

## 1. 一句话结论

已发布 V1 只允许作为玩法行为、数值、平台适配和代码实现参考；V1 及当前工作区中的旧背景、UI、按钮、面板、头像、皮肤、图标、粒子、宣传图和既有美术风格一律不得继承到 V2。V2 所有可见美术从零重新设计并生产，目标是可正式上线的商业化质量。

## 3. 商业质量与竞品对标边界

V2 美术风格没有被 V1 的“糖果机”方案锁定，可以重新探索和选择。可以把《开心消消乐》等头部休闲游戏作为商业完成度标杆，重点对标：

- 一眼可读的核心玩法区和信息层级。
- 明亮、友好、统一且不过度杂乱的色彩组织。
- 有厚度、有按压反馈的真实按钮状态。
- 首页、局内、弹窗、排行、商店、结算属于同一视觉系统。
- 角色在小尺寸下仍清晰，合成反馈有明确层级。
- 完整的 normal、pressed、disabled、selected、loading、empty、offline 和 error 状态。

“对标”不等于复制。不得复刻竞品的角色、关卡地图、Logo、UI 布局、按钮轮廓、图标、字体组合、文案、独特场景或其他可识别表达。最终设计必须是《合成亿仔》的原创视觉系统。

## 4. 美术方向选择门禁

在批量出图前先制作 4–6 个明显不同的风格方向，每个方向至少展示同一套代表内容：

1. 首页氛围与核心入口。
2. 局内玩法仓、HUD 和控制区。
3. 主按钮 normal / pressed / disabled。
4. 通用弹窗和一条排行榜行。
5. 原创 `face_01`、`face_05`、`face_10`。
6. 严格引用本机亿仔源图生成的 `face_11_yizai`。
7. 一次普通合成反馈。

风格方向图只进入 `art/generated/v2-commercial` 和 `art/review/v2-commercial`。用户没有明确选择方向前，不得批量生产 UI Kit、完整头像链或皮肤。

## 6. 新美术生产与导出规则

- Grok 负责从零生成新的视觉母版；程序只负责精确画布、裁切、透明通道、九宫格、文字、数字、布局、点击区和状态切换。
- 所有 UI 文案由 Cocos Label 渲染，生成图不承载按钮中文、分数、昵称、价格、名次、任务进度或错误文案。
- 最终画布尺寸必须符合 `docs/V2.0美术资源需求表_给GPT.md`，不能把错误比例的旧图强拉伸到目标尺寸。
- 按钮必须有真实 normal / pressed / disabled 视觉。pressed 需要位移、厚度和高光变化，不能只做变暗；disabled 需要保留轮廓，不能只降低透明度。
- 需要透明的组件必须交付真实 Alpha，边缘不得有白边、黑边或旧背景残留。
- 所有生成原图、派生图、提示词、参考图、工具版本、SHA256、尺寸和审核结论必须可追溯。

资产流转只允许：

```text
art/prompts/v2-commercial
→ art/generated/v2-commercial
→ art/review/v2-commercial
→ 用户确认
→ art/final/v2-commercial
→ Cocos Bundle
```

任何不在 `art/final/v2-commercial` 且没有 `approved` 审核记录的图片不得进入正式 Cocos Bundle。
