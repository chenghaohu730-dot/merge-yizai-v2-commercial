# 《合成亿仔》完整玩法规则表

## 1. 基础信息

| 项目 | 内容 |
| --- | --- |
| 游戏名 | 合成亿仔 |
| 类型 | 2D 竖屏物理合成小游戏 |
| 平台 | 微信小游戏 |
| 核心目标 | 不断合成更高级抽象头像，最终合成出亿仔 |
| 核心体验 | 简单、魔性、紧张、想再来一局 |
| 技术建议 | Cocos Creator + TypeScript |

## 2. 一句话玩法

玩家控制头像从上方掉落。两个相同等级的头像碰到一起后，会合成下一级头像。头像越来越大、越来越抽象，堆到警戒线以上持续一段时间则游戏结束。最终目标是合成出正式亿仔。

## 3. 主流程

1. 进入游戏后直接开始一局。
2. 系统在顶部生成当前头像和下一个头像预览。
3. 玩家左右移动当前头像。
4. 玩家点击或松手后头像掉落。
5. 头像落入容器并参与物理碰撞。
6. 两个同级头像碰撞后合成下一级。
7. 合成后获得分数，并播放合成反馈。
8. 头像堆过警戒线持续 3 秒，游戏结束。
9. 结算页显示本局分数、最高分、最高合成等级。
10. 玩家可再来一局或分享。

## 3.1 商业化外壳

第一版加入轻量留存和传播闭环，不引入服务器：

| 模块 | 第一版规则 |
| --- | --- |
| 今日目标 | 每日目标为合成到第 5 级，完成后显示连续完成天数 |
| 本地战绩 | 记录累计挑战局数、累计分数、合出亿仔次数 |
| 成绩分享 | 结算页提供分享成绩入口，微信端走小游戏分享能力 |
| 存档方式 | 全部使用本地存档，暂不接账号和服务器 |

## 4. 操作规则

| 操作 | 规则 |
| --- | --- |
| 左右移动 | 手指横向拖动，头像跟随 X 轴移动 |
| 释放头像 | 松手或点击后头像开始下落 |
| 移动边界 | 头像中心不能超过容器左右边界 |
| 下落期间 | 当前头像不可再控制 |
| 新头像生成 | 当前头像稳定释放后，顶部生成下一个头像 |

## 5. 合成规则

| 规则项 | 内容 |
| --- | --- |
| 合成条件 | 两个相同等级头像发生有效碰撞 |
| 合成结果 | 在碰撞中心生成下一级头像 |
| 原头像处理 | 两个原头像消失 |
| 合成延迟 | 建议 0.08-0.15 秒，避免连续误判 |
| 最高等级 | 第 11 级为亿仔 |
| 亿仔之后 | 两个第 11 级可合成高分特效，不再生成第 12 级 |

## 6. 失败规则

| 规则项 | 内容 |
| --- | --- |
| 警戒线位置 | 容器顶部下方约 18%-22% 高度 |
| 触发条件 | 任意头像超过警戒线 |
| 缓冲时间 | 连续超过 3 秒才失败 |
| 缓冲反馈 | 警戒线闪烁，播放紧张提示 |
| 取消失败 | 头像掉回警戒线以下后计时清零 |

## 10. 物理参数建议

| 参数 | 初始建议 |
| --- | --- |
| 重力 | 980 |
| 弹性 | 0.15-0.25 |
| 摩擦 | 0.45-0.65 |
| 线性阻尼 | 0.05 |
| 角阻尼 | 0.1 |
| 最大下落速度 | 1200 |

头像不宜太弹，否则会乱飞；也不能完全不弹，否则合成爽感不足。

## 11. 第一版验收标准

- 可以连续正常玩 5 局。
- 玩家不看说明也知道拖动和释放。
- 合成反馈清楚。
- 失败不是突然死亡，有 3 秒缓冲。
- 能保存最高分。
- 能保存累计挑战、今日目标和亿仔次数。
- 结算页能分享成绩。
- 能合成到第 8 级以上。
- 合成出亿仔时有明显庆祝感。
