# Cocos开发任务清单

## 1. 技术基线

| 项目 | 选择 |
| --- | --- |
| 引擎 | Cocos Creator |
| 语言 | TypeScript |
| 目标平台 | 微信小游戏 |
| 方向 | 2D 竖屏 |
| 存档 | 本地存档 |
| 服务器 | 第一版不做 |

## 2. 推荐场景

| 场景 | 说明 |
| --- | --- |
| `GameScene` | 主游戏场景，打开即玩 |
| `PreloadScene` | 可选，资源多了再加 |

第一版可以只做 `GameScene`，减少复杂度。

## 3. 核心脚本

| 脚本 | 责任 |
| --- | --- |
| `GameManager.ts` | 游戏状态、开始、暂停、结束、重开 |
| `DropController.ts` | 当前头像生成、拖动、释放 |
| `FaceItem.ts` | 单个头像等级、碰撞、合成触发 |
| `MergeManager.ts` | 合成判定、生成新头像、合成特效 |
| `ScoreManager.ts` | 分数、最高分、本地保存 |
| `WarningLine.ts` | 警戒线检测和失败倒计时 |
| `FaceConfig.ts` | 头像等级、分数、尺寸、概率 |
| `UIManager.ts` | 分数、预览、弹窗、按钮 |
| `AudioManager.ts` | 音效播放 |
| `WechatAdapter.ts` | 微信分享、存档、排行榜预留 |

## 4. 第一阶段：灰盒原型

目标：不依赖正式美术，先做可玩。

任务：

- 创建竖屏游戏场景。
- 创建物理容器左右墙和底部。
- 创建圆形头像预制体。
- 实现顶部生成头像。
- 实现手指拖动控制 X 轴。
- 实现松手掉落。
- 实现同等级碰撞合成。
- 实现分数增加。
- 实现最高分保存。
- 实现警戒线 3 秒失败。
- 实现重新开始。

验收：

- 能连续玩 5 局。
- 合成不会频繁误触发。
- 物体不会明显穿模。
- 失败判断有缓冲。

## 5. 第二阶段：正式资源接入

任务：

- 导入 11 个头像 PNG。
- 按等级替换显示图。
- 按等级调整圆形碰撞体大小。
- 导入背景、按钮、弹窗。
- 加入合成闪光。
- 加入分数跳字。
- 加入破纪录提示。
- 加入亿仔合成庆祝特效。

验收：

- 每个头像识别度清楚。
- 亿仔 `MAEE` 在游戏中可见。
- 合成反馈明显。
- UI 不遮挡游戏区域。

## 6. 第三阶段：手感调试

重点参数：

- 重力
- 弹性
- 摩擦力
- 头像尺寸
- 生成概率
- 警戒线高度
- 合成延迟
- 掉落控制速度

验收：

- 开局 30 秒内有多次合成。
- 新手一般能玩 1-2 分钟。
- 熟练玩家能冲击第 9-11 级。
- 合成亿仔难，但不是几乎不可能。

## 7. 第四阶段：微信适配

任务：

- 导出微信小游戏。
- 接入微信开发者工具。
- 测试真机启动。
- 本地最高分保存。
- 分享按钮预留。
- 排行榜接口预留。
- 图片压缩。
- 包体检查。

验收：

- 手机竖屏显示正常。
- 不同屏幕比例不遮挡。
- 首次加载速度可接受。
- 退出重进最高分仍在。
