# 《合成亿仔》交付包导入说明（傻瓜版）

这份说明给接手、测试或上传体验版的人使用。照着做即可，不需要理解源码结构。

## 你会拿到什么

交付包是一个压缩包，名字类似：

```text
merge-yizai-commercial-preview-YYYYMMDD-HHMMSS.zip
```

解压后会看到这些目录：

```text
01_微信小游戏工程
02_上线素材
03_交付文档
04_验证记录
05_网页试玩构建
交付说明.md
双击_打开微信小游戏工程.bat
双击_查看导入说明.bat
双击_自检交付包.bat
自检交付包.ps1
checksums.sha256
```

最省事的方式：

1. 先双击 `双击_自检交付包.bat`。
2. 看到“自检通过”后，双击 `双击_打开微信小游戏工程.bat`。
3. 在微信开发者工具里导入打开的这个工程目录。
4. 不知道下一步做什么时，双击 `双击_查看导入说明.bat`。

## 第一件事：导入微信开发者工具

第一步：打开微信开发者工具。

第二步：点“导入项目”。

第三步：项目目录选择这个文件夹：

```text
01_微信小游戏工程
```

注意：不要选择整个压缩包，也不要选择解压后的最外层目录。只选 `01_微信小游戏工程`。

第四步：如果只是本地试玩，可以先继续使用 `touristappid`。

第五步：如果要上传体验版，必须把 AppID 换成正式小游戏 AppID。

## 第二件事：本地运行检查

导入后点“编译”或“预览运行”。

看到以下内容就说明基本正常：

- 出现《合成亿仔》启动页。
- 点“开始挑战”后进入游戏。
- 拖动头像，松手后头像会掉落。
- 两个一样头像碰到一起会合成更高级头像。
- 顶部能看到分数、最高分、下一个头像。
- 画面里能看到“今日目标”。
- 点暂停按钮能暂停，再点继续能恢复。
- 点底部“声/静”按钮能开关声音。
- 结算页有“再来一局”和“分享成绩”。

## 第三件事：检查分享

第一步：在微信开发者工具里运行游戏。

第二步：点右上角分享，或在结算页点“分享成绩”。

第三步：确认分享卡图片是正式分享图，不是旧概念图。

正式分享图长这样：

```text
02_上线素材/share_card_1200x960.png
```

## 第四件事：检查素材

上传后台时优先使用这些文件：

| 用途 | 文件 |
| --- | --- |
| 小游戏图标 | `02_上线素材/app_icon_1024.png` |
| 分享图 | `02_上线素材/share_card_1200x960.png` |
| 宣传横图 | `02_上线素材/store_cover_1280x720.png` |

注意：`01_微信小游戏工程/assets/ui/app_icon.png` 是包内备用小图，不是后台上传首选图标。

## 第五件事：填写后台资料

后台资料可以直接参考：

```text
03_交付文档/08_上线资料包.md
```

建议填写：

| 字段 | 内容 |
| --- | --- |
| 名称 | 合成亿仔 |
| 一句话简介 | 抽象头像一路合成，最后冲出带 MAEE 的亿仔 |
| 类型 | 休闲 / 合成 / 物理 |

隐私说明参考：

```text
本小游戏仅在用户设备本地保存游戏进度和分数记录，用于展示最高分、今日目标和本地挑战次数；当前版本不收集、上传或共享个人身份信息。
```

## 第六件事：真机试玩

上传体验版前，至少用真机玩 10-20 局。

重点看：

- 有没有卡顿。
- 音效会不会太吵或太小。
- “声/静”按钮能否正常开关声音。
- 头像会不会穿出容器。
- 警戒线失败是否太突然。
- 分享图在微信聊天里有没有被裁得很奇怪。
- 亿仔头像里的 `MAEE` 是否看得清。

## 如果出问题

优先看这几个文件：

```text
交付说明.md
03_交付文档/07_商业化交付清单.md
03_交付文档/08_上线资料包.md
04_验证记录
```

如果是 AppID、预览码、上传体验版失败，一般不是游戏代码问题，需要检查微信开发者工具登录账号和小游戏后台权限。

如果要看自动长测结果，打开：

```text
04_验证记录/device-checks/gameplay-soak/summary.json
04_验证记录/device-checks/gameplay-soak/iphone-12-soak-final.png
```
