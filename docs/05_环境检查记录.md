## Cocos Dashboard 安装尝试

2026-06-11 已尝试使用 `winget` 安装 `Cocos.CocosDashboard`。

结果：

- `winget search` 可找到 `Cocos.CocosDashboard 2.2.1.2616`。
- `winget install --id Cocos.CocosDashboard --silent --accept-package-agreements --accept-source-agreements` 下载官方安装包时返回 `403 Forbidden`。
- 使用同一官方下载地址配合浏览器 User-Agent 直连下载，仍返回 `403 Forbidden`。

官方文档说明 Cocos Creator 的常规路径是先下载 Dashboard，再通过 Dashboard 管理引擎版本和项目。因此当前阻塞点是 Dashboard 安装包下载源访问失败，不是项目代码本身。
