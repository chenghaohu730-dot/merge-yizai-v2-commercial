# 11级抽象头像美术清单

## 总原则

前 10 级是原创抽象头像，最后 1 级是正式亿仔。

美术关键词：圆形头像、魔性、抽象、明亮、清晰、适合物理碰撞、适合截图分享。

禁止直接复制现成 IP、真人脸、原表情包、平台水印图、明星脸、品牌包装图。可以参考网络抽象梗的情绪气质，但必须原创化。

## 头像通用规格

| 项目 | 规格 |
| --- | --- |
| 文件格式 | PNG |
| 背景 | 透明背景 |
| 画布 | 512 x 512 |
| 主体位置 | 居中 |
| 碰撞形状 | 尽量接近圆形 |
| 边缘 | 清楚、厚描边 |
| 风格 | Q 版抽象头像 |
| 文字 | 前 10 级不放文字，第 11 级亿仔头饰必须有 `MAEE` |

## 1级：芽芽豆

定位：最小、最呆、像刚开机。

视觉描述：

- 蓝绿色小圆脸。
- 眼睛空空的，间距略大。
- 嘴巴很小，像没反应过来。
- 表情不要太可爱，要有一点呆滞感。

原创参考气质：评论区小豆脸、评论区小豆梗类抽象表情的低能量感。

文件名：`face_01_sprout_bead.png`

## 2级：桃桃泡芙

定位：无辜、猫感、有点欠。

视觉描述：

- 奶白或浅米色圆脸。
- 有轻微猫耳轮廓，但不要画成真实猫咪 IP。
- 嘴巴微张，像在发出奇怪声音。
- 眼神无辜，但略微发懵。

原创参考气质：空耳梗猫感、空耳洗脑感。

文件名：`face_02_peach_puff.png`

## 3级：心心果冻

定位：礼貌假笑，俏皮斜眼。

视觉描述：

- 粉色圆团脸。
- 嘴角强行上扬。
- 眼睛半睁，带一点无语。
- 整体像在说“好的呢”。

原创参考气质：粉猪俏皮斜眼脸、礼貌但生无可恋。

文件名：`face_03_heart_jelly.png`

## 4级：阳光摇摇

定位：一看就像要开始摇。

视觉描述：

- 黄色或橙色圆脸。
- 头部轻微倾斜。
- 两只眼睛方向不一致。
- 嘴巴歪，表情有节奏感。
- 可以加一点动感线，但主体仍然圆。

原创参考气质：摇摆梗摇头、魔性跳舞头像。

文件名：`face_04_sun_wiggle.png`

## 5级：蓝莓惊惊

定位：评论区发疯，表情用力过猛。

视觉描述：

- 蓝色大圆脸。
- 眼睛瞪大。
- 嘴巴裂开式夸张张开。
- 脸部可以有轻微裂纹图案，但不能血腥。

原创参考气质：评论区小豆梗、抽象评论区、破防发疯。

文件名：`face_05_sky_spark.png`

## 6级：奶油笑笑

定位：胖、憨、笑到失控。

视觉描述：

- 奶黄色胖圆脸。
- 脸颊鼓起。
- 嘴巴大笑，身体感圆滚。
- 不要做成现成 IP外形，不要有龙角和现成 IP标志轮廓。
- 重点是“奶油感 + 大笑 + 胖团”。

原创参考气质：现成 IP大笑类抽象梗的夸张快乐，但必须完全原创。

文件名：`face_06_cream_smile.png`

## 7级：小芽贤者

定位：皱巴巴、老头感、老猫感，但不做负面虐待暗示。

视觉描述：

- 灰米色或淡棕色圆脸。
- 大眼袋。
- 稀疏眉毛。
- 嘴角下垂。
- 脸部皱纹夸张但干净。

原创参考气质：年龄梗、年龄梗、疲惫但荒诞。

文件名：`face_07_seed_sage.png`

## 8级：葡萄电电

定位：突然炸毛，碰撞时很爽。

视觉描述：

- 紫蓝色或亮黄色脸。
- 眼睛瞪圆。
- 嘴巴大张像在哈气。
- 周围有闪电形装饰。
- 表情要冲击强，但不要恐怖。

原创参考气质：哈气猫、闪电年龄梗、炸毛表情。

文件名：`face_08_grape_zap.png`

## 9级：火苗哈哈

定位：抽象程度明显升级。

视觉描述：

- 大头圆脸。
- 眯眼狂笑。
- 嘴巴占脸部很大比例。
- 可以有不对称五官。
- 色彩高饱和，但边界清楚。

原创参考气质：大笑抽象头像、鬼畜笑脸。

文件名：`face_09_flame_grin.png`

## 10级：星冠团团

定位：最终抽象头像，离谱但仍然可爱。

视觉描述：

- 体积明显大。
- 混合歪嘴、评论区小豆梗眼、摇摆梗姿态、年龄梗皱纹、哈气感。
- 脸上元素丰富，但不要糊成一团。
- 颜色可以更强烈，适合作为亿仔前一档。

原创参考气质：抽象界大集合。

文件名：`face_10_crown_star.png`

## 11级：亿仔

定位：最终目标，正式 IP 奖励感。

强制视觉规范：

- 白熊主体。
- 橙黄色口鼻区。
- 黑色大鼻子。
- 粗眉毛。
- 头部必须有装饰物。
- 头饰正面必须清晰显示 `MAEE`。
- `MAEE` 不能遮挡、不能镜像、不能拼错。

表现建议：

- 做成圆形头像，适配物理碰撞。
- 表情自信、开心，有“终于合出来了”的奖励感。
- 可以加金色光圈或星星，但不能挡住 `MAEE`。

文件名：`face_11_yizai.png`

## 美术验收清单

- 11 个头像放在同一页面看，等级递进明显。
- 每个头像缩小到 80px 仍能看清表情。
- 前 10 级都不是现成 IP 直接复制。
- 亿仔的 `MAEE` 在 512px 原图和游戏缩放后都可辨认。
- 头像轮廓接近圆形，适合圆形碰撞体。
- 风格统一，不像从不同地方拼来的图。
