# 迁移步骤与验证清单

## 安装后第一轮

1. 启动 `D:\CocosCreator\versions\3.8.8\CocosCreator.exe`。
2. 用 Cocos 打开 `game/cocos-creator-v2`。
3. 让 Creator 自动生成 `.meta`。
4. 创建 Boot、Home、Game、Result、Task、Shop、Rank 场景。
5. 创建 `FaceBall.prefab`，挂 `FaceItem`。
6. 将 `GameManager`、`GameArea`、`DropController`、`MergeManager`、`WarningLine`、`ScoreManager`、`EffectManager` 挂到 Game 场景。
7. 把按钮挂上 `ButtonStateAudio`，绑定三态 SpriteFrame 和按钮音效。

## 核心玩法验收

- 能拖动投放位置。
- 松手后头像掉落。
- 相同等级碰撞合成。
- 合成加分。
- 合成特效和音效出现。
- 第 11 级亿仔出现时 `MAEE` 清晰可见。
- 失败线连续 3 秒后结算。
- 暂停、继续、重开可用。

## 大厅和数据验收

- 首页开始、任务、排行榜、商店都是真按钮。
- 最高分实时刷新。
- 今日目标实时刷新。
- 亿仔币余额实时刷新。
- 结算页显示本局分数、最高合成、奖励。
- 退出重进后最高分、金币、任务、皮肤、本地榜不丢。

## 屏幕适配验收

至少检查：

- 750 x 1334 基准屏。
- iPhone 长屏。
- 常见安卓长屏。
- 短屏。

要求：

- 玩法区清晰。
- 球体比背景醒目。
- HUD 不压住玻璃仓。
- 底部控制台不遮挡失败判断。
- 背景不整张拉伸变形。

## 微信验证

1. Cocos 构建微信小游戏。
2. 微信开发者工具导入构建目录。
3. 检查启动、分享、音频、本地缓存。
4. 真机试玩 10 局以上。
5. 记录问题到 `tests/playtest-notes`。
