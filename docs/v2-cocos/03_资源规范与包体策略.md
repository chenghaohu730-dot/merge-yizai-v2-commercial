# 资源规范与包体策略

## 美术来源门禁

- V1 和当前旧 Cocos 的全部图片、旧音频及既有视觉风格禁止进入 V2 正式 Bundle。
- V2 可见美术必须来自 `art/final/v2-commercial` 中带 `approved` 记录的本轮 Grok 新资源。
- 旧资源不得通过复制、缩放、改色、裁切、拼接、图生图或风格迁移变相进入。
- 任何出现亿仔的资源必须能追溯到 `art/source/yizai_highest_source.png` 及其锁定 SHA256。
- 当前从旧 `art/final` 拷贝的背景、按钮、头像和皮肤均为无效占位，不能作为正式资源或 Golden Slice 证据。

## 主包资源

主包只放启动最小集：

- Boot、Loading 和正式错误页必要资源。
- 平台适配、随包 manifest 和本地 Bundle 加载器。
- 不把完整头像链、皮肤或局外页面塞进主包。

当前位置：

```text
game/cocos-creator-v2/assets/resources
```

## 本地普通分包资源

```text
game/cocos-creator-v2/assets/bundles/skins
game/cocos-creator-v2/assets/bundles/events
```

- `core_game`：11 级经典头像链、首页、游戏页、结算页、基础 UI 和基础音频。
- `meta_ui`：任务、成就、商店、排行、设置和通用弹窗。
- 每套 `skin_*`：独立的本地 Asset Bundle，并构建为微信普通分包。
- 活动和扩展音频也只能随审核包以内置本地分包交付。

所有皮肤随游戏包内置；玩家完成解锁后直接加载并使用，不做 CDN、远程下载或下载缓存。每个 Bundle 都必须进入版本、SHA256、准确字节和总包体门禁。

## 亿仔 IP 资源规则

凡是正式亿仔形象，必须先真实使用本机 `art/source/yizai_highest_source.png` 作为唯一身份参考，再保留：

- 白熊主体。
- 橙黄色口鼻区。
- 黑色大鼻子。
- 粗眉毛。
- 头部装饰物。
- 头饰正面清晰英文 `MAEE`。

`MAEE` 不可省略、替换、拼错、镜像、倒置或遮挡。

## 按钮规则

每个按钮必须有：

- normal。
- pressed。
- disabled。
- 点击范围。
- 点击音效反馈。

当前目录中已有的按钮图是旧占位，不代表三态已完成。新按钮批准后才可放入：

```text
game/cocos-creator-v2/assets/resources/ui/buttons
```

对应清单：

```text
game/cocos-creator-v2/assets/data/button-states.json
```
