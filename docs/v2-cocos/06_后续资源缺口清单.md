# 后续资源缺口清单

## 必补资源

| 资源 | 说明 |
| --- | --- |
| Cocos 场景文件 | 需安装 Cocos 后由 Creator 生成 |
| Cocos Prefab | `FaceBall`、`StateButton`、`MergeFx`、`ScorePop` |
| 最终 UI 切图 | 当前资源可迁移，但需按最终 Cocos UI 重新验收 |
| 合成粒子 | 普通合成、大合成、亿仔庆祝三档 |
| 飘字动画 | 分数、破纪录、奖励亿仔币 |
| 商店皮肤资源 | 只换外观，不改数值 |
| 微信开放数据域工程 | 好友榜独立域 |
| 云开发函数 | 全服榜提交和拉取 |

## 需要重点复核

- 亿仔头像缩放到游戏实际尺寸后，`MAEE` 仍清楚可见。
- 按钮三态在手机上足够明显。
- 背景不能抢球体视觉焦点。
- 玻璃仓视觉边界和碰撞墙必须完全一致。
- 皮肤不能偷偷改变球半径、质量、弹性、概率和分数。
