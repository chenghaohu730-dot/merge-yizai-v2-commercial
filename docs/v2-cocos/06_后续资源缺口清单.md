# 后续资源缺口清单

## 必补资源

| 资源 | 说明 |
| --- | --- |
| Cocos 场景文件 | 需安装 Cocos 后由 Creator 生成 |
| Cocos Prefab | `FaceBall`、`StateButton`、`MergeFx`、`ScorePop` |
| 最终 UI 切图 | 当前旧资源不可迁移；须在 4–6 个新风格方向获批后，由 Grok 从零生产并按精确尺寸导出 |
| 合成粒子 | 普通合成、大合成、亿仔庆祝三档 |
| 飘字动画 | 分数、破纪录、奖励亿仔币 |
| 默认头像与商店皮肤资源 | 旧头像和旧皮肤图片全部作废；按新批准角色表从零生产，只换视觉、不改数值 |
| 微信开放数据域工程 | 好友榜独立域 |
| 云开发函数 | 全服榜提交和拉取 |

## 需要重点复核

- 正式资源没有复用、改色、缩放、裁切或图生图继承旧图。
- 每个涉及亿仔的任务都记录并真实使用本机唯一参考图。
- 亿仔头像缩放到游戏实际尺寸后，`MAEE` 仍清楚可见。
- 按钮三态在手机上足够明显。
- 背景不能抢球体视觉焦点。
- 玻璃仓视觉边界和碰撞墙必须完全一致。
- 皮肤不能偷偷改变球半径、质量、弹性、概率和分数。
