# Cocos 场景节点蓝图

基准分辨率：750 x 1334，竖屏。Canvas 使用固定宽度适配，长屏向上下扩展，不能整图拉伸。

## Boot

```text
Boot
└─ BootController (Boot.ts)
```

职责：初始化微信分享菜单、预加载核心配置、进入 Home。

## Home

```text
Home
├─ Root
│  ├─ Background
│  ├─ BestScoreLabel
│  ├─ TodayGoalLabel
│  ├─ CoinLabel
│  ├─ StartButton
│  ├─ TaskButton
│  ├─ RankButton
│  └─ ShopButton
└─ HomeView (HomeView.ts)
```

所有数字由 Label 实时渲染，不烘焙在图片里。

## Game

```text
Game
├─ GameRoot
│  ├─ Background
│  ├─ TopHud (GameHud.ts)
│  ├─ GameArea (GameArea.ts)
│  │  ├─ GlassView
│  │  ├─ LeftWall
│  │  ├─ RightWall
│  │  ├─ Floor
│  │  ├─ WarningLine
│  │  └─ FaceRoot
│  ├─ DropController (DropController.ts)
│  ├─ MergeManager (MergeManager.ts)
│  ├─ WarningLineController (WarningLine.ts)
│  ├─ ScoreManager (ScoreManager.ts)
│  ├─ EffectManager (EffectManager.ts)
│  ├─ BottomConsole
│  │  ├─ PauseButton
│  │  ├─ RestartButton
│  │  └─ SoundButton
│  └─ PauseOverlay
└─ GameManager (GameManager.ts)
```

强制规则：视觉玻璃仓、物理墙体、失败线、投放范围全部从同一个 `GameArea` 尺寸派生。
