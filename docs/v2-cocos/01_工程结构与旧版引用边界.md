# 工程结构与旧版引用边界

## 新工程

```text
game/cocos-creator-v2
├─ assets/data                 # 可验证配置数据
├─ assets/resources/faces      # 主包核心头像资源
├─ assets/resources/ui         # 主包首屏和核心玩法 UI
├─ assets/resources/audio      # 主包基础音效
├─ assets/bundles/skins        # 后续皮肤分包
├─ assets/bundles/events       # 后续活动分包
├─ assets/scripts              # Cocos TypeScript 组件
├─ assets/scenes               # Cocos 安装后生成真实场景
└─ assets/prefabs              # Cocos 安装后生成真实预制体
```

## 旧版引用边界

| 旧目录 | 可参考 | 不继承 |
| --- | --- | --- |
| `game/web-prototype` | 玩法行为、数值、输入手感、测试方法和代码思路 | DOM/Canvas UI 架构及全部可见美术 |
| `game/wechat-minigame` | 微信分享、本地存档、平台适配和已发布行为 | 单文件 Canvas 结构、旧音频及全部可见美术 |
| 旧 `art/final`、截图、导出包 | 历史审计和 V1 追溯 | 任何 V2 视觉母版、Grok 参考图、Golden Slice 或 Bundle 资源 |
| `art/source/yizai_highest_source.png` | 所有涉及亿仔任务的唯一正式身份参考 | 不涉及亿仔的普通 UI/角色生成参考 |

旧项目不删除、不覆盖；但 V2 美术必须从零重制，不能改色、缩放、裁切、拼接或图生图继承旧图。完整规则见 `docs/13_《合成亿仔》V2.0美术全量重制硬性边界.md`。

## 模块边界

| 模块 | 责任 |
| --- | --- |
| `GameArea` | 统一派生玻璃仓、墙体、地板、失败线、投放范围 |
| `DropController` | 当前球、下一个球、拖动、释放 |
| `FaceItem` | 等级、碰撞体、合成触发 |
| `MergeManager` | 合成锁、合成延迟、生成新球、合成事件 |
| `WarningLine` | 3 秒失败缓冲 |
| `ScoreManager` | 本局分数、最高分、最高等级 |
| `GameManager` | 局内状态和跨模块协调 |
| `TaskService` | 每日任务进度和领取亿仔币 |
| `ShopService` | 皮肤购买和选择，只改外观 |
| `LocalRankService` | 本地榜 |
| `WechatAdapter` | 微信分享和平台能力入口 |
