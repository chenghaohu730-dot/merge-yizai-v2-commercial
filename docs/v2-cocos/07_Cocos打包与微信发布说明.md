# Cocos 打包与微信发布说明

## 前置条件

- 安装 Cocos Creator 3.8 LTS。
- 用 Cocos 打开 `game/cocos-creator-v2`。
- 场景、预制体、脚本挂载完成。
- 使用真实小游戏 AppID 替换测试 AppID。
- 微信开发者工具可正常打开。

## Cocos 构建建议

构建目标：

```text
微信小游戏
```

建议设置：

| 项目 | 建议 |
| --- | --- |
| 设计分辨率 | 750 x 1334 |
| 方向 | 竖屏 |
| 首场景 | Boot |
| 主包 | Boot、Home、Game、Result、Task、Shop、Rank、核心头像、核心 UI、基础音频 |
| 分包 | 皮肤、活动、后续扩展资源 |
| 压缩纹理 | 后续真机验证后开启 |

## 微信开发者工具检查

1. 导入 Cocos 构建出的微信小游戏目录。
2. 检查 AppID。
3. 打开本地调试。
4. 运行首屏。
5. 检查控制台是否有资源丢失。
6. 试玩至少 10 局。
7. 检查分享、音频、本地存档。
8. 使用真机预览码验证触控、音频和屏幕适配。

## 上传前必须过的清单

- 进入 Home 正常。
- 开始游戏按钮可点击，有按下态和音效。
- 任务、排行榜、商店都能打开和返回。
- 掉落、碰撞、合成、失败线、结算闭环完整。
- 本局分数、最高合成、最高分、亿仔币都实时刷新。
- 退出重进后数据不丢。
- 亿仔 `MAEE` 清晰可见。
- 主包资源没有放入非必要皮肤和活动资源。
- 微信开发者工具无关键报错。
