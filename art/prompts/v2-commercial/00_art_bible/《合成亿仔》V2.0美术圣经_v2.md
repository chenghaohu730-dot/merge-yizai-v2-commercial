# 《合成亿仔》V2.0 美术圣经 v2

状态：新风格探索与 Golden Slice 生产基准；用户未选定方向前禁止批量出图。
设计画布：750 × 1334，竖屏。
正式运行时：Cocos Creator 3.8.8；动态文字、数字、布局、点击区域和状态切换由程序负责。

## 1. 不可变来源边界

- 已发布 V1 只作玩法行为、数值、平台能力、测试方法和代码参考。
- V1、旧 `art/final`、当前旧 Cocos 资源、旧截图和既有糖果机风格全部禁止作为 V2 美术母版或 Grok 参考图。
- 禁止对旧图复制、改色、缩放、高清化、裁切、拼接、描边、图生图或风格迁移后冒充新资源。
- V2 所有可见美术由 Grok 从零生产新母版，再做可追溯的确定性导出。
- 详细硬性规则以 `docs/13_《合成亿仔》V2.0美术全量重制硬性边界.md` 为准。

## 2. 视觉目标

目标不是“比 V1 好一点”，而是达到可正式上线和宣传的头部休闲小游戏商业完成度：

- 三秒内看懂首页主入口和局内核心玩法区。
- 色彩明亮友好但有层级，玩法仓不抢头像。
- 按钮、弹窗、卡片、图标、角色和特效拥有统一材质与光照逻辑。
- normal、pressed、disabled、selected、loading、empty、offline、error 状态完整。
- 角色和按钮缩小到真实手机尺寸后仍清晰。
- 首页、局内、任务、商店、排行、结算和分享物料属于同一原创产品系统。

可以把《开心消消乐》等头部休闲游戏作为完成度、色彩节奏、信息层级、触感和反馈密度标杆，但不得复制其角色、Logo、图标、地图、页面构图、按钮轮廓、文案或可识别商业外观。

## 3. 风格方向探索

正式色板、材质和光照尚未锁定。Golden Slice 前先提交 4–6 个明显不同的原创方向，不能只改主色：

1. 高完成度明亮休闲消除感：清晰大色块、丰富但受控的高光和奖励反馈。
2. 精致 3D 玩具世界：圆润实体材质、明确厚度、统一棚拍式光照。
3. 现代 2.5D 插画：立体分层、干净轮廓、轻材质、较低包体压力。
4. 童话绘本游乐场：柔和笔触与立体 UI 结合，保持玩法区清楚。
5. 可选的原创品牌方向：由 Grok 提出，但必须能落地为分层 UI 和小尺寸组件。
6. 可选的克制高级方向：减少装饰密度，用角色和反馈承担情绪价值。

每个方向必须用相同内容和尺寸展示，便于比较，不能用不同功能量制造偏差。用户选择后，将该方向的色板、材质、光源、圆角、描边、阴影和图标透视写入独立 `approved-style.json`，再批量生产。

## 4. 通用 UI 生产规则

- 背景、机器/外壳、玩法仓、HUD、控制台、弹窗、按钮和图标必须分层交付。
- 背景不得烘焙按钮、数字、任务进度、排行榜信息或可变文案。
- 除正式 Logo 与确定性校正后的 `MAEE`，所有文字由 Cocos Label 渲染。
- 需要拉伸的面板交付明确九宫格安全区；装饰不得进入拉伸区。
- 需要透明的组件必须有真实 Alpha，边缘无白边、黑边和背景残留。
- 设计尺寸、锚点、显示区域和触控区域分别记录，不用整图透明热区冒充 UI。

按钮状态最低标准：

- normal：结构完整，主材质、高光、边框和底部厚度清楚。
- pressed：视觉整体下移 6 px，顶部高光减弱，底部厚度缩短；Cocos 热区保持不动。
- disabled：降低饱和和明度但保留轮廓、材质和图标；不能只降低透明度。
- 同一按钮的三态保持相同画布、锚点、外轮廓和内容位置。

## 5. 前 10 级原创头像

- 从零建立角色身份，不继承旧头像的轮廓、五官、配色、名字或贴图。
- 只能借鉴困倦、疑惑、兴奋、礼貌阴阳、爆笑、眩晕、自信、好运、炫耀、期待等抽象情绪。
- 不得复制真人脸、网络表情包、现成 IP、平台水印或受保护的独特造型。
- 每级同时改变轮廓节奏、眉眼关系、嘴型、主辅色和一个安全区内的小装饰，不能只换颜色。
- 512 × 512 透明画布，圆心 256/256，主体最大直径 460 px，四边透明安全区至少 26 px。
- 在 128 px、80 px 和 64 px 预览中仍能由轮廓与五官区分等级。

## 6. 亿仔唯一身份锁

唯一正式参考：`art/source/yizai_highest_source.png`
SHA256：`6B6C74F39FB8A92E8CD7B23BDD729D2E14BD76E38DE4C0CB0AD528638A7BCD12`

任何出现亿仔的生成、编辑、动画或视频任务都必须在 job 和 manifest 中记录并真实使用该参考图。若 Grok 当前能力无法读取参考图，该任务停止，不得降级为纯文字生成。

正式亿仔必须同时满足：

- 白熊主体。
- 橙黄色椭圆口鼻区。
- 居中的黑色大鼻子。
- 粗黑眉毛。
- 头部有装饰物或头饰。
- 头饰正面清晰、正向、无遮挡地出现唯一拼写 `MAEE`。
- 不镜像、不倒置、不改字母、不用近似字符替代。

允许把材质、光照和场景适配到用户批准的新风格，但不能改变身份、物种和核心五官。`MAEE` 必须人工放大复核，必要时使用从正式参考源提取并批准的确定性字标覆盖。

## 7. Golden Slice 清单

每个风格方向只生产：

1. 首页分层合成预览。
2. 局内分层合成预览。
3. 主按钮 normal / pressed / disabled。
4. 通用弹窗和一条排行榜行。
5. 全新原创 `face_01`、`face_05`、`face_10`。
6. 使用唯一参考图生成的 `face_11_yizai`。
7. 一次普通合成特效方向。

先对比 4–6 个方向；用户选出短名单后，每项再做 2–3 个候选。未确认前不得批量生成完整 UI、完整头像链或任何整套皮肤。

硬性否决项：使用旧图、缺少亿仔参考图、错误或缺失 `MAEE`、现成 IP/真人脸、竞品可识别复制、动态文字烘焙、物理安全圆越界、组件无法分层、伪按钮三态、AI 乱码、水印或尺寸不符。

## 8. 资产流转与证据

```text
art/prompts/v2-commercial
→ art/generated/v2-commercial
→ art/review/v2-commercial
→ 用户确认
→ art/final/v2-commercial
→ Cocos
```

每个生成物必须记录：生成工具与版本、实际命令、原始提示词、参考图、生成时间、原文件 SHA256、原始尺寸、派生处理参数、最终尺寸、Alpha 检查和审核结论。

只有 `art/final/v2-commercial` 中状态为 `approved` 的新资源才能进入正式 Bundle。旧图、概念图、联系表、未批准候选和尺寸错误的派生图一律禁止导入。
