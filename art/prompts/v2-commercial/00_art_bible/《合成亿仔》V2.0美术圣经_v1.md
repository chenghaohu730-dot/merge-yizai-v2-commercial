# 《合成亿仔》V2.0 美术圣经 v1

状态：Golden Slice 生产基准，未通过 Golden Slice 前禁止批量出图。
设计画布：750 × 1334，竖屏。
正式运行时：Cocos Creator 3.8.8；动态文字、数字、进度和点击区域由程序负责。

## 1. 一句话视觉定位

一台由亿仔经营的高品质糖果合成机：圆润、明亮、有真实玩具材质和机械层次，但玩法仓必须安静清楚，头像永远是第一视觉焦点。

不采用扁平色块拼 UI、纯代码渐变、廉价霓虹、现成手游模板、真实玩具品牌、真人脸或已有表情包角色。

## 2. 色板

| 角色 | 色值 | 使用边界 |
| --- | --- | --- |
| MAEE 橙 | `#FF9500` | 亿仔口鼻、核心奖励、高价值确认 |
| 糖果粉 | `#F4517F` | 机器主壳和首要品牌氛围，不覆盖全部屏幕 |
| 明亮金 | `#FFC53D` | 主按钮边框、金币、成功高光 |
| 蓝莓蓝 | `#2E8DD6` | 次级功能、信息态、玻璃反光 |
| 工装海军蓝 | `#07346B` | 亿仔工装、深色文字底、结构阴影 |
| 奶油白 | `#FFF2D3` | 面板主体和呼吸空间 |
| 成功绿 | `#65B946` | 已完成、领取、可用状态 |
| 警戒橙红 | `#FF583D` | 警戒线、危险状态；不用于常驻大面积背景 |
| 禁用灰 | `#9B948C` | 禁用态，仍保留结构和可识别轮廓 |

单屏以糖果粉、MAEE 橙、奶油白为主；蓝、绿、紫只作信息分组。禁止全屏同时高饱和，玩法仓内部整体饱和度和对比度比头像低一档。

## 3. 材质、光照和阴影

- 机器外壳：烤漆玩具塑料，圆角处有窄高光，不能像黏腻果冻。
- 金色部件：暖金电镀，控制高光面积，不能大面积发白。
- 面板：奶油色微颗粒塑料或软质搪胶，不使用纸张纹理。
- 玻璃仓：边缘有蓝白反光，中心保持清透；不叠重雾、强脏污或大面积高光。
- 头像：细腻搪胶/软糖玩具材质，五官清楚，轮廓近圆，不出现皮肤毛孔和真人质感。
- 主光从左上 35° 入射；右下只保留柔软环境阴影。
- UI 投影统一向下 6–10 px，模糊 12–20 px；禁止不同组件各用一套光源。

## 4. UI 形制

- 大面板圆角：36 px；小卡片：24 px；主按钮：48–60 px。
- 外边框为暖金 8–14 px，内侧有 2–4 px 奶油高光，深层结构用海军蓝或棕红阴影。
- 主按钮 normal：橙金主体、顶部窄高光、底部深橙厚度。
- pressed：整体下移 6 px、顶部高光减弱、底部厚度缩短；热区不移动。
- disabled：降低饱和和明度，保留外形与图标，不靠透明到几乎看不见。
- 图标正视或轻微 3/4 俯视，统一粗轮廓和圆润倒角；禁止混入细线扁平图标。
- 生成图不得烘焙动态文字、分数、昵称、进度、价格或名次。除正式 Logo 和经人工校对的 `MAEE` 外，文字均由 Cocos 渲染。

## 5. 首页与局内层级

首页：Logo/品牌区 → 亿仔或合成机视觉中心 → 开始按钮 → 今日目标/最高分 → 任务、排行、商店。背景只承载氛围，不把按钮和动态数据画死。

局内：顶部 HUD → 投放器 → 低干扰玻璃仓 → 头像球 → 底部控制台。`physics_rect` 与视觉仓共用同一套坐标；任何装饰不得侵入球体活动区。

## 6. 前 10 级原创头像规则

- 只借鉴“困、疑惑、兴奋、阴阳怪气、爆笑、眩晕、自信、好运、炫耀、期待”等情绪，不复制现成角色和真人脸。
- 每级同时变化基础配色、眉眼关系、嘴型和一个不外伸的小装饰；不能只换颜色。
- 同一等级在 80 px 显示时仍能由轮廓与五官读出；不能依赖小字和细碎纹理。
- 512 × 512 透明画布，圆心 256/256，主体最大直径 460 px，四边透明安全区至少 26 px。
- 任何耳朵、冠饰、星星、发髻或道具不得突破碰撞安全圆。

代表等级锁定方向：

- `face_01`：困倦紫豆，低等级、轻微塌眼、无现成角色轮廓。
- `face_05`：奶白爆笑球，大开口但仍保持原创五官比例。
- `face_10`：紫白太空期待球，高级感来自头盔环和星徽，不使用已有宇航员 IP 造型。

## 7. 亿仔品牌身份锁

唯一正式参考：`art/source/yizai_highest_source.png`。源文件 SHA256：`6B6C74F39FB8A92E8CD7B23BDD729D2E14BD76E38DE4C0CB0AD528638A7BCD12`。

任何正式亿仔必须同时满足：

- 白熊主体。
- 橙黄色椭圆口鼻区。
- 居中的黑色大鼻子。
- 粗黑眉毛。
- 头部有红色安全帽或当前主题明确规定的头饰。
- 头饰正面清晰、正向、无遮挡地出现唯一拼写 `MAEE`。
- 不镜像、不倒置、不改字母、不用相近字替代。

生成模型不得独立重画关键 `MAEE` 后直接入库。Golden Slice 中优先以参考图编辑保持身份；正式资源还要人工逐像素校对，必要时用已批准字标覆盖错误生成文字。

## 8. 特效规则

- 普通合成：12 帧、12 fps、透明序列，中心爆开的小型糖晶火花和柔光环。
- 高级合成和亿仔成功可以提高亮度与粒子数量，但不得遮挡球脸或 `MAEE`。
- 粒子形状使用原创糖晶、圆点、短弧和小星芒贴图；禁止用程序圆形、emoji 或纯线条冒充正式特效。
- 特效颜色取当前两颗球的主色与明亮金，不另造冲突色板。

## 9. Golden Slice 清单与闸门

只生产并评审：

1. 首页完整概念图。
2. 局内完整概念图。
3. 主按钮 normal / pressed / disabled。
4. 通用弹窗和一条排行行。
5. `face_01`、`face_05`、`face_10`。
6. `face_11_yizai`。
7. 一次普通合成特效代表帧/序列方向。

每项先做 2–3 个候选。自动检查后，只把 1–2 个合格方向提交人工确认。未确认前不得批量生成完整 UI、全部头像或五套皮肤。

硬性否决项：错误或缺失 `MAEE`、现成 IP/真人脸、动态文字烘焙、物理安全圆越界、光源不一致、玩法仓干扰过强、组件无法分层、明显 AI 乱码/水印。
