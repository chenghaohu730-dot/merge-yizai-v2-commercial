# 合成亿仔

《合成亿仔》是一个 2D 竖屏微信小游戏。

玩家把原创抽象头像不断合成，越合越离谱，最终合成出正式亿仔。

## 当前状态

项目已经进入商业化试玩交付包阶段：

- 完整玩法规则
- 11 级抽象头像美术清单
- Cocos 开发任务清单
- 项目目录结构
- 网页灰盒/试玩原型
- 11 个正式头像 PNG
- 启动页、暂停、合成反馈、粒子、结算
- 今日目标、累计挑战、亿仔次数
- 设置系统、本地排行榜系统、成就系统
- 网页端局后分享文案
- 微信小游戏端分享菜单和成绩分享按钮
- 基础音效和静音开关
- 小游戏图标、分享图、宣传横图
- 上线资料包和商业化交付压缩包

## 本地试玩

进入网页原型目录：

```text
D:\01_Codex源码项目\微信小游戏\game\web-prototype
```

安装依赖后启动：

```text

npm run assets
npm run dev -- --port 5173
```

浏览器打开：

```text
http://127.0.0.1:5173
```


```text

```

## 核心规则

- 前 10 级头像为原创抽象头像。
- 第 11 级为亿仔。
- 亿仔必须保留白熊主体、橙黄色口鼻区、黑色大鼻子、粗眉毛。
- 亿仔头饰正面必须清楚显示 `MAEE`。
