# 合成亿仔 微信小游戏工程

这是《合成亿仔》的原生微信小游戏工程，不依赖 Cocos。

## 导入方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择：

```text
D:\01_Codex源码项目\微信小游戏\game\wechat-minigame
```

4. 当前 `appid` 是 `touristappid`，用于本地预览。上传体验版前需要替换为正式小游戏 AppID。

## 当前能力

- 竖屏 Canvas。
- Matter.js 物理掉落。
- 11 级头像合成。
- 最终亿仔头像包含 `MAEE`。
- 分数、最高分、本地存档。
- 开始页、暂停、失败线、结算页。
- 今日目标、本地挑战次数、亿仔合成次数。
- 微信右上角分享菜单。
- 结算页“分享成绩”按钮。
- 基础音效：按钮、掉落、合成、高级合成、亿仔庆祝、失败。

## 当前交付状态

当前工程适合导入微信开发者工具做本地试玩和给团队验收核心手感。正式上传体验版前，还需要替换真实小游戏 AppID，并完成开发者工具预览、真机扫码、隐私与合规资料检查。
